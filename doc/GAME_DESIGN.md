## 农耕系统

### 土地状态

```
草地 (Grass)
    ↓ [锄头]
耕地 (Tilled)
    ↓ [水壶]
浇水 (Watered)
    ↓ [种植种子] + [每日浇水]
作物生长
    ↓
成熟 (Mature) → [收获]
```

## 任务系统

### 任务类型

1. **收获任务** - 收集特定数量的作物
2. **社交任务** - 与NPC对话或送礼
3. **收集任务** - 收集特定资源
4. **交付任务** - 将物品交给NPC

### 任务奖励

- 金币奖励
- 种子/物品奖励
- 好感度提升
- 解锁新内容

## AI Agent 设计考量

### 观察空间

Agent可以观察到的信息：
- 玩家状态 (位置、体力、金币、背包)
- 时间信息 (日期、时间、季节)
- 周围环境 (附近格子、NPC)
- 任务状态 (进行中的任务)

### 动作空间

Agent可以执行的动作：
- 移动 (上/下/左/右)
- 使用工具 (锄/浇水/收割)
- 种植/收获
- 购买/出售
- 社交 (对话/送礼)
- 时间控制 (等待/睡觉)

### 奖励设计建议

```python
# 示例奖励函数
def calculate_reward(state, action, next_state):
    reward = 0

    # 金币增长
    reward += (next_state.gold - state.gold) * 0.01

    # 任务完成
    for quest in next_state.completed_quests:
        if quest not in state.completed_quests:
            reward += 10

    # 作物收获
    reward += count_harvested(next_state) - count_harvested(state)

    # 友好度提升
    for npc in next_state.npcs:
        old = get_npc_friendship(state, npc.id)
        new = npc.friendship
        reward += max(0, new - old) * 0.1

    # 体力惩罚 (鼓励休息)
    if next_state.energy < 20:
        reward -= 1

    return reward
```
